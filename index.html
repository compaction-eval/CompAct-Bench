01 / THE SIGNAL

A shorter context can still lose the plot.

Long-horizon agents accumulate actions, observations, failed attempts, and partial progress until the working context hits a hard boundary. CompAct-Bench asks a consequential question: can the same agent finish the task after that history is compacted?

02 / THE PROTOCOL

A controlled rewind, then a fresh run.

Every instance starts from a trajectory the executor already solved. The only thing that changes is the working context crossing a boundary.

01

Collect

Run the fixed executor three times. Keep only tasks solved every time, then record a successful reference trajectory.

02

Compact

Cut the trajectory at 25%, 50%, or 75%. An evaluated LM turns Hb into a 10% representation Mb.

03

Resume

Restore the boundary environment and give the executor the original task, compacted context, and a matched action budget.

04

Measure

Success means the continuation completes the original task. No reference summary. No extra turns.

Acc(Cφ)=successful continuationsall compaction instances

04 / FAILURE MODES

Two ways to lose the thread.

Compaction failures are not one thing. Omission tends to make agents repeat themselves; distortion makes them believe the wrong state.

A

Omissions → exhaustion

Critical omissions and progress/state loss make the executor reopen work it already finished. Budget drains into redundant tools and repeated questions.

COPSLLR
B

Distortion → premature commitment

Factual or constraint distortion turns tentative evidence into a settled conclusion. The agent commits early, skips verification, or follows the wrong goal.

A good compactor does more than remember.
